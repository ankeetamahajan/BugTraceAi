
# BugTrace AI

## Agentic Hybrid RAG for Software Bug Investigation

BugTrace AI is an AI-powered software debugging assistant
designed to investigate software errors using historical
incidents and technical documentation.

## Planned Features

- Retrieval-Augmented Generation (RAG)
- Metadata-based filtering
- Semantic vector search
- BM25 keyword search
- Hybrid retrieval and reranking
- Agentic workflows using LangGraph
- Knowledge graph integration using Neo4j
- MCP-based tool integration
- Source-grounded investigation reports
- Retrieval evaluation and automated testing

## Planned Technology Stack

Python, LangChain, LangGraph, Hugging Face, ChromaDB,
BM25, Neo4j, MCP, FastAPI, Streamlit, Docker and Pytest.

## Project Status

Under active development.
